2. Installation depuis zero

Prerequis serveur

  • PHP 8.3+ avec extensions : gd, mbstring, mysql, xml, zip, curl, intl
  • MySQL 8+
  • Composer 2+
  • Node.js 18+ + npm

Etapes d'installation

1. Cloner le depot Git :

git clone [URL_DEPOT] marquage-textile
cd marquage-textile

2. Installer les dependances PHP :

composer install

3. Installer les dependances JS et compiler :

npm install
npm run build

4. Copier et configurer l'environnement :

cp .env.example .env
php artisan key:generate

5. Creer la base de donnees et migrer :

mysql -u root -e "CREATE DATABASE marquage_textile"
php artisan migrate

6. Creer le lien symbolique storage :

php artisan storage:link

7. Importer les donnees fournisseurs :

php artisan import:toptex
php artisan import:valento
php artisan import:solo
php artisan import:imbretex

6. Systeme de facturation

Les factures sont au format Factur-X (normes francaises 2027) :

  • PDF/A-3 avec XML embarque (norme EN 16931)
  • Numerotation sequentielle : FA-YYYYMM-XXXX
  • Statuts : deposit (acompte), paid (payee), settled (soldee)
  • Stockees dans storage/app/private/invoices/
  • Disponibles 18 mois cote client, indefiniment en back-office

Flux paiement CB

Systempay IPN → markAsPaid() → facture auto + mail 1 + mail 2/11

Flux virement

Client confirme → mail 1 + mail 3 + mail 8
Admin "Valider paiement" (Filament) → markAsPaid() → facture + mails
Admin "Solder" → settleInvoice() → facture soldee + mail 12

Boutons Filament (OrderResource)

  • Valider paiement : genere facture + envoie mails (integral ou acompte 50%)
  • Solder : met a jour facture en "soldee", regenere PDF, envoie mail 12
  • Facturer : genere facture manuellement (pour virements sans paiement prealable)
  • Archiver : masque la commande (visible uniquement si facture payee/soldee)
  • Supprimer : supprime les commandes annulees

  • Fichiers BAT + clients des commandes archivees > 60 jours : supprimes (factures conservees)

  • Visites > 6 mois : purgees

9. Deploiement en production (OVH)

Points critiques

  • LOG_LEVEL=warning dans .env (PAS debug, sinon le disque OVH se remplit)
  • SYSTEMPAY_MODE=PRODUCTION
  • APP_DEBUG=false
  • APP_ENV=production

Commandes de deploiement

composer install --no-dev --optimize-autoloader
npm install && npm run build
php artisan migrate --force
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan storage:link

Cron a configurer

* * * * * cd /home/marquage-textile && php artisan schedule:run >> /dev/null 2>&1

Probleme connu : ancien site PrestaShop

L'ancien site crashait car le flux de visiteurs gonflait la memoire/disque OVH. Le nettoyage automatique (maintenance:cleanup) tourne chaque nuit a 4h pour eviter ce probleme.

11. Fonctionnalites principales

  • Catalogue : Plus de 5000 produits de 5 fournisseurs, synchronisation automatique des stocks et prix.
  • Devis en ligne : Bloc devis amovible (FloatingQuote), recommandation automatique de technique (moins cher + premium), multi-logos, groupes figes.
  • Commandes : Checkout avec paiement CB (Systempay) ou virement, acompte 50%, flux BAT pour marquage.
  • Facturation : Factures Factur-X (normes 2027), PDF/A-3 avec XML, numerotation sequentielle, export Excel.
  • Back-office : Filament 3 avec dashboard interactif, statistiques, chat live, gestion commandes/factures/produits.
  • Chat : Widget chatbot cote client (FAQ + suivi commande + chat live), interface admin avec polling.
  • SEO : URLs optimisees, JSON-LD, meta-descriptions, contenu technique, sitemap, redirections 301.
  • Securite : Honeypot anti-bot sur tous les formulaires, rate limiting sur le chat, sanitization XSS.
  • Maintenance : Nettoyage automatique nocturne (sessions, cache, logs, fichiers, visites).
  • Images : Toutes les images en local (pas de hotlink fournisseur), compressees < 150 Ko, nommage SEO.
